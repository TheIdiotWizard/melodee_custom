# Melodee Custom 1.3.9

Updated FMTONE and ANALOG4 presets; FMTONE algorithm visualizer.

## FMTONE: Updated and restored presets

Four FMTONE presets have been updated with richer settings from user bank sounds:
**DXBASS** now runs through the M2K chain (CUT 52, RES 82) with its operator levels and FM ratio
tuned for a punchy DX-style bass. **GROWL** has tighter filter tracking (M2K, CUT 42, RES 43,
DIST 14) and refined operator ratios for a cleaner growl character. **FIFTH RING** has adjusted
frequency ratios on the carrier pair for a cleaner fifth interval. **SAW ACID** (the M2K
chain) now has CUT 24, RES 48 — a tighter, drier sound closer to the original MONO2K preset.

The four original FMTONE presets from 1.3.5 are back: **TINE EP**, **BELL**, **FM BASS**, and
**GLASS PAD**. Each uses the classic two-operator (C + A) algorithm with envelopes tuned for
their respective characters.

## FMTONE: Algorithm visualizer

The GRAPH page on FMTONE now shows an operator diagram for each of the eight ALGO settings, the
same way FM6 does. Operators are labelled C, A, 1, 2 (carrier and modulators), with routing
arrows showing which operators modulate which, the output bus at the bottom, and a feedback
loop on operator B2 where applicable.

## ANALOG4: Removed ACID preset

The ACID preset has been removed from ANALOG4. The remaining presets are SAW BASS, PWM LEAD,
SYNC LEAD, and WARM PAD.

Everything from [1.3.7](RELEASE_1.3.7.md) is included.
